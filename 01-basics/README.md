# 01. Основы: приостановка и конкурентность

1. Прочитай [теорию на русском](THEORY.md) или [на английском](THEORY_EN.md).
2. Открой [условия задач](TASKS.md) и файл `src/main/kotlin/course/Task01.kt`.
3. Запусти задачу командой из её условия, затем сравни наблюдения с ожидаемыми.
4. Если застрял, открой [решения и объяснения](SOLUTIONS.md). Вопросы обсуждаем в чате.

Упражнения 01–04: вставка и исправление готового кода. 05–08: доработка заготовки. 09–12: самостоятельная реализация (выполненные тобой файлы сохранены). Каждая задача запускается отдельно, поэтому одна незавершённая не мешает другим.

**Пример:**

```bash
./gradlew :01-basics:task01 --console=plain
```
