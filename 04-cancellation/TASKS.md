# Задачи: Отмена, таймауты и очистка

Перед началом прочитай [теорию на русском](THEORY.md) или [теорию на английском](THEORY_EN.md). Выполняй задачи 01–12 по порядку. Каждая находится в своём `TaskNN.kt`. В консоли видны отметки времени, имя потока и результат проверки. Зелёный вывод Gradle означает лишь успешный запуск: проверь также строки `OK` и ожидаемый результат.

Если задача зависла, останови процесс (`Ctrl+C`) и проверь завершение дочерних корутин, Flow или Channel. Для экспериментов с планировщиком не проверяй точные миллисекунды обычных запусков.

## 04.12 · Отмена сессии и гарантированная очистка

**Уровень:** Самостоятельная реализация механизма корутин; данные, имитация работы, логирование и проверка уже есть. [Открой файл задачи](src/main/kotlin/course/Task12.kt).

Создай сессию с двумя одновременно работающими детьми и отмени её через 40 мс. Каждый ребёнок должен успеть выполнить **приостанавливающую** очистку даже после отмены. Общий ресурс закрывается ровно один раз, только после обоих детей; его блокирующая очистка выполняется вне вызывающего потока. Дождись завершения всей группы перед итоговым сообщением.

Здесь нужно совместить структурированное родительство, переключение контекста из модуля 03 и правила отмены. Данные, счётчики и журнал готовы.

**Запуск:**

```bash
./gradlew :04-cancellation:task12 --console=plain
```

**Что должно быть видно в консоли:** Две дочерние очистки перед закрытием ресурса, затем итоговый порядок и три строки `OK`.
