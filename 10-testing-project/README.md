# 10. Тестирование и итоговый проект

1. Прочитай [теорию на русском](THEORY.md) или [на английском](THEORY_EN.md).
2. Открой [условия задач](TASKS.md) и файл `src/main/kotlin/course/Task01.kt`.
3. Запусти задачу командой из её условия, затем сравни наблюдения с ожидаемыми.
4. Если застрял, открой [решения и объяснения](SOLUTIONS.md). Вопросы обсуждаем в чате.

Упражнения 01–04: вставка и исправление готового кода. 05–08: доработка заготовки. 09–12: самостоятельно реализуй механизм корутин; сценарий, данные и вывод подготовлены. Каждая задача запускается отдельно, поэтому одна незавершённая не мешает другим.

**Пример:**

```bash
./gradlew :10-testing-project:task01 --console=plain
```
