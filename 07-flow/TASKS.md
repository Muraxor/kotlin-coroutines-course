# Задачи: Flow: холодные потоки и операторы

Перед началом прочитай [теорию на русском](THEORY.md) или [теорию на английском](THEORY_EN.md). Выполняй задачи 01–12 по порядку. Каждая находится в своём `TaskNN.kt`. В консоли видны отметки времени, имя потока и результат проверки. Зелёный вывод Gradle означает лишь успешный запуск: проверь также строки `OK` и ожидаемый результат.

Если задача зависла, останови процесс (`Ctrl+C`) и проверь завершение дочерних корутин, Flow или Channel. Для экспериментов с планировщиком не проверяй точные миллисекунды обычных запусков.

## 07.12 · Два потребителя телеметрии

**Уровень:** Самостоятельная реализация механизма корутин; данные, имитация работы, логирование и проверка уже есть. [Открой файл задачи](src/main/kotlin/course/Task12.kt).

Два потребителя одновременно подписываются на один холодный источник. Каждый должен отбросить отрицательные измерения и повторы подряд, удвоить остальные, а после сбоя датчика добавить `-1`. Сохрани оба списка результатов в порядке потребителей. Одновременно веди общую сумму полученных значений так, чтобы ни одно обновление не потерялось.

Здесь понадобятся приёмы предыдущих модулей: одновременный запуск независимых операций, обработка ошибки и безопасное обновление общего состояния. Данные, журнал и проверки уже готовы.

**Запуск:**

```bash
./gradlew :07-flow:task12 --console=plain
```

**Что должно быть видно в консоли:** Источник запущен дважды; каждый список равен `[2, 4, 10, -1]`, общая сумма `30`, две строки `OK`.
